# Pauline Website

A small static website for Pauline — simple pages for home, products, shopping and contact.

## Preview
- Open `index.html` in your browser to preview the site locally.

## Project structure
- `index.html` — Home page
- `products.html` — Products page
- `shopping.html` — Shopping/cart page
- `registration.html` — Registration form
- `contact.html` — Contact form (current file)
- `css/style.css` — Stylesheet
- `images/` — Images used by the site
- `media/` — Additional media files

## How to push to GitHub
1. Initialize repository (if not already): `git init`.
2. Stage files: `git add .`.
3. Commit: `git commit -m "Initial commit"`.
4. Create a remote repository on GitHub or use the GitHub CLI `gh repo create`.
5. Add the remote and push: `git remote add origin <URL>` then `git push -u origin main`.

## Notes
- Replace `<URL>` with your repository HTTPS or SSH URL (e.g. `https://github.com/USERNAME/REPO.git`).
- If you prefer SSH, make sure your SSH key is added to your GitHub account.
